# 조선 국정 회의 — 실시간 모둠 대항 조선왕조 정책 시뮬레이션

한국사 수행평가용 웹 게임입니다. 교사가 방을 만들고 교실 화면에 띄우면, 모둠이 방 코드로 접속해 같은 왕의 시대를 동시에 플레이합니다. 모든 모둠의 나라 모습·제출 현황·선택·순위가 실시간으로 공유됩니다.

- 왕 5명(세종·광해군·영조·정조·흥선대원군) × 역사적 사건 7개
- 사건마다 대책 3개 중 선택 + 세금·예산 슬라이더 + 결정 근거
- 교사가 **결과 공개**를 누르면 모둠별 선택 분포, 실제 역사, 나라 모습, 순위가 동시에 공개
- 지표(국고·민심·왕권·국방·민생·문화)에 따라 나라 그림이 바뀜, 지연 효과·위기·전쟁·결말 분기
- **모둠별 왕 선택**: 방을 만들 때 '모둠이 직접 선택'을 고르면 모둠마다 다른 시대를 플레이하고, 결과 공개 때 시대별로 비교
- **현대 제도 카드(통합사회 융합)**: 누진세·권력 분립·국채·FTA 등 14장의 현대 제도를 조선식으로 바꾼 카드(`cards.js`). 모둠당 3장, 사건마다 1장
- 끝나면 성찰 3문항 제출, 모든 기록은 구글 시트에 저장

## 화면
- `index.html` 모둠 화면 (학생 태블릿·노트북)
- `host.html` 교사 화면 (교실 프로젝터)

## 서버(구글 Apps Script) 설정
1. 새 구글 시트 → [확장 프로그램] > [Apps Script]에 `apps-script/Code.gs` 전체를 붙여 넣고 저장
2. [배포] > [새 배포] > 유형 **웹 앱**, 실행 **나**, 액세스 **모든 사용자** → 배포 → URL 복사
3. `config.js`의 `SERVER_URL`에 URL을 넣고 푸시 → Vercel 자동 재배포
- 시트 탭: `기록`(사건마다 모둠별 선택·근거·지표), `제출`(최종 성찰), `_rooms`(방 상태 백업)

## 개발
- 사건 데이터: `scenarios.js` / 카드: `cards.js` / 규칙: `core.js` / 서버: `server/server.gs.js`
- `./build.sh` → `apps-script/Code.gs` 생성(시나리오+규칙+서버를 한 파일로)
- `node server/mock.js 8787` → Apps Script 없이 로컬 테스트 (`http://localhost:8787/host.html?server=http://localhost:8787/exec`)
