# 조선 국정 회의 — 모둠 대항 조선왕조 정책 시뮬레이션

한국사 수행평가용 웹 게임입니다. 모둠이 세종·광해군·영조·정조·흥선대원군 중 한 왕의 시대로 들어가 7개의 역사적 사건마다 대책을 고르고, 세금과 예산을 조절해 국고·민심·왕권·국방·민생·문화 여섯 지표를 관리합니다.

- 매 사건 뒤 실제 역사에서 왕이 고른 선택이 공개됩니다.
- 몇몇 정책은 몇 해 뒤에 효과(지연 효과)가 나타나고, 지표가 20 아래로 떨어지면 민란·정변·재정 파탄 위기가 옵니다.
- 광해군·흥선대원군은 실제와 같은 선택을 하면 실제와 같은 결말(인조반정, 하야)을 맞습니다.
- 끝나면 실제 역사와 비교하는 성찰 3문항을 쓰고 보고서를 제출합니다.

## 파일
- `index.html` 게임 / `board.html` 교사용 실시간 순위판
- `scenarios.js` 사건·선택지·효과 데이터(수정 가능) / `core.js` 게임 규칙 / `config.js` 시트 주소
- `apps-script/Code.gs` 구글 시트 저장용 Apps Script

## 구글 시트 연결
1. 새 구글 시트 → [확장 프로그램] > [Apps Script]에 `apps-script/Code.gs`를 붙여 넣고 저장
2. [배포] > [새 배포] > 웹 앱, 실행 **나**, 액세스 **모든 사용자** → URL 복사
3. `config.js`의 `SHEET_URL`에 URL을 넣고 푸시 → Vercel 자동 재배포
