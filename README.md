# 조선 국정 회의 — 의정부 회의판 (조선 후기)

한국사 수업용 실시간 모둠 대항 정책 시뮬레이션 웹 게임입니다. 모둠은 하나의 **의정부(나라)**가 되고, 학생은 각자 기기로 **영의정**과 **6조 판서**(이·호·예·병·형·공조)를 맡습니다. 모든 모둠이 같은 사건을 함께 맞고, 사건마다 6조가 정책을 하나씩 골라 묶어 의정부의 결정을 상신합니다.

- 만든 사람: 예당고등학교 이동민 (한국사) · 2026. 11. 24. 공개 수업
- 실제 주소: 학생 https://joseon-policy-game.vercel.app · 교사 `/host.html` · 대사헌 `/daesaheon.html?code=방코드` · 참관 `/host.html?watch=방코드`

## 사건 7개 (1592 ~ 1894)
임진왜란(1592) · 명과 후금 사이에서(1619, 광해군 중립 외교) · 새로운 도시 화성(1794) · 홍경래의 난(1811) · 강화도 조약(1876) · 갑신정변(1884) · 동학 농민 운동(1894)

## 기능
- **6조 정책 선택**: 사건마다 각 조가 정책 3개 중 하나를 **근거**와 **비슷한 현대 정책**을 써서 고르고, 영의정이 근거를 써서 상신
- **시너지·충돌**: 여러 조의 정책이 맞물리면 협력 보너스 점수, 부딪히면 감점. 결과 공개 때 '시너지 도감'
- **천하 형세 인포그래픽**: 나라별 색·깃발, 6개 지표(국고·민심·왕권·국방·민생·문화) 변화, 순위
- **돌발 이벤트**: 논의 중 무작위로 발생, 영의정이 대응 선택
- **5분 의논 타이머**: 교사·학생·참관 화면 상단. 교사는 ±1분, 다시 5분
- **귀양 연출**: 결과 공개 때 40점 미만 의정부의 영의정이 실제 유배지로 귀양. 다시 40점 위로 오르면 해배
- **AI 대사헌 (Claude)**
  - 학생 화면: 판서·영의정이 고른 정책에 대사헌이 질문 → 학생이 말(음성 인식)이나 글로 대답 → 평과 두 번째 질문 → 총평(상·중·하). 점수와 무관, 기록에 저장
  - 대사헌 전용 화면: 별도 컴퓨터에 띄우면 사건·돌발·결과·종료 때 "전하, 아뢰옵니다"로 스스로 보고하고, 선생님이 말로 물으면 말로 대답. 입·수염·눈이 움직이는 캐릭터
- **참관 모드**: 외부 참관자에게 교사 화면을 읽기 전용으로 실시간 공유
- **교사 관리**: 게임 끝내기(성찰 단계), 방 종료(학생 접속 해제), 엑셀 기록(`기록`·`제안`·`제출`·`문답` 시트)
- `?demo=1`: 서버 없이 한 브라우저 안에서 가상 의정부와 함께 체험

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 학생 화면 |

## 내 학교에 설치하기 (무료로 시작)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. vercel.com에서 **Add New → Project**로 그 저장소를 가져와 배포합니다.
3. Vercel 프로젝트 → **Storage → Create Database → Upstash for Redis(Free)** → 프로젝트에 연결합니다. `KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 들어갑니다.
4. (AI 대사헌을 쓰려면) console.anthropic.com에서 크레딧을 충전하고 API 키를 만든 뒤, Vercel → Settings → Environments → Production → Environment Variables에 `ANTHROPIC_API_KEY`로 넣고 **Redeploy**합니다. 키가 없어도 게임은 돌아가고, 학생 문답은 준비된 질문으로 진행됩니다.
5. Vercel → Settings → **Deployment Protection**에서 Vercel Authentication을 'Preview만'으로 두어야 학생이 로그인 없이 들어옵니다.

- 방 상태는 7일, 기록은 30일 보관됩니다.
- 사건 내용을 바꾼 뒤에는 `./build.sh`를 실행하고 커밋해야 서버에도 반영됩니다.
- (선택) 구글 Apps Script 서버: `apps-script/Code.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 URL을 `config.js`의 `SERVER_URL`에 넣으면 기록이 시트에 바로 쌓입니다.
